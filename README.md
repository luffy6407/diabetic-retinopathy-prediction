# Diabetic Retinopathy Prediction

A machine learning classification project developed to predict diabetic retinopathy using patient clinical measurements.

## Project Overview

The project includes exploratory data analysis, data preprocessing, feature standardization, model building, model evaluation, and deployment using Streamlit.

## Input Features

- Age
- Systolic Blood Pressure
- Diastolic Blood Pressure
- Cholesterol

## Models Evaluated

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Support Vector Machine
- XGBoost

## Final Model

Support Vector Machine (SVM) was selected as the final model.

- Accuracy: 77.08%
- Precision: 77.14%
- Recall: 78.77%
- F1 Score: 77.95%
- ROC-AUC: 83.48%

## Deployment

The trained SVM model and StandardScaler are integrated into an interactive Streamlit application that provides predictions, dataset analysis, model performance, and project insights.

## Disclaimer

This project was developed for educational and machine learning demonstration purposes and is not intended for medical diagnosis or treatment decisions.
